FeedLog never sees these credentials — this login belongs to the host app. That is exactly what the widget's auth.login hook is for.

Widget demo controls @feedlog/widget
Connection Your FeedLog org address. The live widget needs a FeedLog backend reachable here. Embed path (SDK embedPath option). The page the widget loads in its iframe. SDK default is /widget/embed.
Org SSO secret The real SDK-integration input. In production this lives in your backend's env and signs JWTs there — never in the browser. This demo signs client-side to stand in for your backend, so getToken() returns a freshly-signed JWT each call (no expiry to babysit). Generate one in FeedLog under Developer → SSO.

host auth: off omits the auth option entirely — the integration a product with no user system of its own would write. The widget then has no host identity, and the embed page mints its own guest on the first message. Needs Guest posting switched on for the org.
